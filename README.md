# Customer-Support-Chatbot-using-Machine-learning
    Customer-Support-Chatbot-using-Machine-learning is a chatbot project designed to provide customer support and automate responses. It includes login and            registration functionality with a database stored in phpMyAdmin.

Features

    User authentication (login & registration)
    
    Database storage in phpMyAdmin
    
    AI-powered chatbot responses
    
    Secure and scalable architecture

Installation

      Clone the repository:
      
          git clone <https://github.com/MNandini01/Customer-Support-Chatbot-using-Machine-learning-.git>
      
      Navigate to the project folder:
      
          cd Customer-Support-Chatbot-using-Machine-learning
      
      Install dependencies (if applicable):
      
          pip install -r requirements.txt  # For Python projects
     

Database Setup

        Open phpMyAdmin and create a new database.
        
        Import the provided SQL file to set up tables.
        
        Update the database credentials in the configuration file.

Usage

    Run the chatbot server:

        python app.py  # If using Python
        node server.js  # If using Node.js
